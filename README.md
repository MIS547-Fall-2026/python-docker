# python-docker

This directory contains sample code for running a flask web app.

When submitting your assignment, you will commit the newly-created Dockerfile and .dockerignore file along with a completed `docker run` command.


- The sample code is forked from [Python Docker Example](https://github.com/estebanx64/python-docker-example)
- The containerization guidance is borrowed from [Docker's Python Language Guide](https://docs.docker.com/language/python).
